** What to do
 1. Define a stop point for every SICP session, and write the next action before closing the book: not "continue SICP" but "Exercise 1.16." An unfinished task
    with a written next step stops demanding rehearsal; one with no next step doesn't.
 2. Stop interleaving. The pull you feel is reward-prediction: SICP is novel, self-directed, ungraded; 408 is repetitive and graded. So make SICP contingent,
    not parallel: 408 block first, then SICP as the earned block. This converts the pull into leverage instead of a competitor.
 3. Hard timer on the SICP block. When it rings, close it mid-thought if necessary — that's the kejime signal, and having a written next step is what makes
    stopping tolerable.
 4. Carry a capture card during review. When an SICP thought arrives, write the question down and go back to 408. Goal is not zero thoughts; it's not acting
    on them. The card resolves the loop cheaply.
 5. Make 408 review active (timed problem sets, recall, past papers), not re-reading. Passive review is what SICP outcompetes most easily; active work is a
    fair fight.
