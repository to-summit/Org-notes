* LaTeX TiKz
Recently, I found a very good [[https://pgf.sourceforge.net/pgf_CVS.pdf][tutorial]] of tikz, which is a powerful plot package in LaTeX.

Here are some demos when I follow the book: 
#+BEGIN_SRC latex
  \documentclass{article}

  \usepackage{tikz}

  \begin{document}

  We are working on: \tikz \draw (-1.5, 0) -- (1.5, 0) -- (0, -1.5) -- (0, 1.5);
  \begin{tikzpicture}
    \draw (-1.5, 0) -- (1.5, 0);
    \draw (0, -1.5) -- (0, 1.5);
  \end{tikzpicture}

  A very cool inline small ellipse: \tikz \draw[rotate=30] (0, 0) ellipse (6pt and 2pt);.

  Use Bezier Curve to plot a circle:
  \begin{tikzpicture}
    \draw (-1.5, 0) -- (1.5, 0);
    \draw (0, -1.5) -- (0, 1.5);
    \draw (-1, 0) .. controls (-1, 0.555) and (-0.555, 1) .. (0, 1)
    .. controls (0.555, 1) and (1, 0.555) .. (1, 0);
  \end{tikzpicture}
              
  Use the `circle' operation:
  \begin{tikzpicture}
    \draw (-1.5, 0) -- (1.5, 0);
    \draw (0, -1.5) -- (0, 1.5);
    \draw (0, 0) circle (1);
    \draw (0, 0) rectangle (0.5, 0.5);
    \draw (-0.5, -0.5) rectangle (-1, -1);
    \draw[step=0.5, gray, very thin] (-1.4, 1.4) grid (1.4, -1.4);
  \end{tikzpicture}

  \end{document}
#+END_SRC
