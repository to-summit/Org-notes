### Personal Org-based Notes

[Org-mode](https://en.wikipedia.org/wiki/Org-mode) is a **strong** tool in emacs to do any text related. *The best way to learn something is to use it in practice.* So I create this repository to do it. This will record all the **study** process under Linux. I also create a [obsidian-based notes](https://github.com/to-summit/Notes) repo for recording under Windows.
